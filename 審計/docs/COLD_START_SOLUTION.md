一、問題定義

  平台硬約束（不可協商）：

    #1 平台不出錢    — 不對任何市場注資（無種子池、無做市商資金）
    #2 平台不蝕錢    — 任何情境下平台 P&L ≥ 0
    #3 平台只賺抽水  — 利潤來自投注額的 8% 手續費，不靠價差

  冷啟動問題：

    當一個新賽事市場的總資金池為 $0 時，傳統 Parimutuel
    （同注分彩法）的賠率引擎無法運作：

      - opponentPool = 0 → calculateDynamicOdds() 返回 null → 拒絕投注
      - 安全帽 (safe cap) 觸底 → 顯示賠率 = 1.01 → 用戶觀感極差
  
  這是結構性問題，不是參數調優能解決的。Parimutuel 的保險機制
  本質上依賴對手盤資金存在，$0 池時數學上無法定義賠率。


二、方案演進歷史

  V1-V3  種子池（Seed Pool）
         平台注入 $30/市場 → 對手盤永大於 0
         否決原因: 違反 #1（平台出錢）

  V4     固定賠率做市商（Fixed-Odds Bookmaker）
         池小時平台做莊，用先驗機率定價，限額控風險
         否決原因: 違反 #3（單場可能虧損）

  V5     零抽水 Parimutuel（Zero-Margin）
         margin=0%, returnRate=1.0, P&L 恆為 $0
         否決原因: 用戶不公平（不同場抽水率不同）

  V6     每場鎖定返還率（Per-Match Locked Return Rate）
         第一筆投注鎖定整場返還率，全場一致
         否決原因: 跨閾值大額投注逃稅

  V7     抽水注入對手盤（Fee-Funded Opponent Pool）
         8% 抽水自動轉入對手盤，永不失靈
         狀態: 當選 ✅

  V7.1   加入返佣 + 體驗金因素
         佣金部分不計入對手盤；體驗金全額注入
         狀態: 當前版本 ✅


三、V7.1 核心機制

  3.1 基本原則

    每筆投注的 8% 抽水在鏈上拆分為三部分：
      POOL (92%)  → 資金池，用於贏家派彩
      HOUSE       → 平台收入（8% 的 1-commissionRate）
      COMMISSION  → 推薦人返佣（8% 的 commissionRate）

    在冷啟動期（總池 < $0.50），引擎將 HOUSE 部分虛擬注入
    對手盤用於賠率計算。這不是真實資金轉移——只是計算層的
    對手盤擴充，使賠率引擎可以正常產出賠率。

  3.2 buildFeeFundedPools 算法

    輸入:  真實投注分布 { H: $0.50, D: $0, A: $0 }
    參數:  profitMargin=0.08, commissionRate=0.3

    步驟1: 計算抽水
      totalFee = $0.50 × 0.08 = $0.04

    步驟2: 拆分 house/commission
      commissionPortion = $0.04 × 0.3 = $0.012
      housePortion      = $0.04 − $0.012 = $0.028

    步驟3: housePortion 平分注入對手盤
      perOpponent = $0.028 / 2 = $0.014
      DRAW  += $0.014
      AWAY  += $0.014

    輸出: 有效分布 { H: $0.50, D: $0.014, A: $0.014 }
         有效的 opponentPool = $0.028（來自真實抽水，不來自平台）

  3.3 賠率計算

    以注入後的分布進行標準 Parimutuel 賠率計算：

      opponentPool > 0 → 不再拒絕
      odds floor = 1.00  → 不觸底到 1.01

  3.4 平台盈虧驗證

    情境A: HOME 勝出（用戶投注選項）
      平台已收抽水 $0.04（鏈上已拆分）
      需支付用戶 $0.50 × odds(H)
      因 returnRate=0.92, opponent 注入來自已收抽水
      淨 P&L = 抽水收入 − 額外支出 ≥ 0

    情境B: DRAW/AWAY 勝出（無人投注選項）
      真實資金 $0.46 無人領取 → 遞延下場
      平台已收抽水 $0.04（不受影響）

    核心保證: 對手盤資金（注入部分）永遠少於已收取的抽水。
              即使對手盤選項勝出，平台 P&L ≥ 0。


四、返佣因素

  用戶的佣金率由推薦人等級決定，三檔可選：

    commissionRate = 30%  →  HOUSE = 5.6% of bet, 注入 $0.028/邊
    commissionRate = 50%  →  HOUSE = 4.0% of bet, 注入 $0.020/邊
    commissionRate = 70%  →  HOUSE = 2.4% of bet, 注入 $0.012/邊

  佣金越高 → 可用於對手盤的資金越薄 → 賠率越貼近 1.00
  但只要 commissionRate ≤ 1.0，housePortion ≥ 0，對手盤永不為零。

  體驗金投注（useBonus=true）:
    effectiveCommissionRate = 0（平台送的虛擬幣，無真實佣金支出）
    → 8% 全額注入對手盤（$0.040/邊），注入效率最高


五、冷啟動閾值與過渡

  池大小        模式            對手盤來源            賠率下限
  ──────────────────────────────────────────────────────────
  < $0.50       抽水注入        抽水的 house portion    1.00

  已自然累積到足以替代注入機制的程度，系統無感切換。

八、三個硬約束的滿足證明

  #1 平台不出錢
     對手盤資金來自用戶自己的抽水（house portion），
     平台 $0 注資。所有計算均為虛擬擴充。

  #2 平台不蝕錢
     對手盤注入資金 = 已收抽水總額的子集。
     對手盤選項勝出時需支付的獎金 ≤ 已收抽水。
     平台 P&L 在任何結果下均 ≥ 0。

  #3 平台只賺抽水
     每筆投注正常收 8% 手續費，不中斷。
     佣金支出由推薦人等級決定（30%/50%/70%），
     不受冷啟動影響。
